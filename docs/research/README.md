# Research notes

Literature notes, model and dependency evaluations, and implementation guidance. The `researcher` agent writes here, and humans can too.

- One file per topic, named `short-topic.md`, for example `sde-sketching-paper.md` or `mlflow-vs-filesystem-store.md`.
- Sections: question and decision informed, sources with version or date read, findings, options compared, recommendation and confidence, implementation guidance, and open questions.
- Label each finding as stated in the proposal as summarized in [PROJECT.md](../PROJECT.md), verified in the source, or inference.
- Add durable sources to [REFERENCES.md](../REFERENCES.md). Notes feed decisions, but only ADRs in [decisions](../decisions/) make them binding.
